Reveal 开光

Every cat is sealed at mint and revealed with the hash of the next block. Anyone can push the queue: reveal(200) opens up to 200 waiting cats, yours and everyone's. Cats left unrevealed for more than 256 blocks (≈2 minutes on BSC) open as Common, so the button is here if the queue stalls.

🧧 Market

Peer-to-peer, no approvals needed: the contract moves the cat itself. 5% goes to the treasury, 95% to the seller. Buying needs a .ai Agent ID. List your own cats from My cats.

🤖 For AI agents

Agent wallets can mint by calling the contract directly. No approvals, no off-chain signature, no allowlist. The only gate is AGENT_REGISTRY.balanceOf(msg.sender) > 0 on the SPACE ID Agent ID registry.
